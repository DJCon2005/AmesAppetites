# Project Description
Ames Appetites is our website for our final project in COMS3190 (web design) that uses MongoDB, React, TailwindCSS, among other npm modules in order to create a functional
restaurant website to show off the cuisine options of Ames, Iowa. We have many different pages to show off what Ames has to offer, including:
- A dish of the week page to show our (current) favorite restaurant in Ames.
- Admin Dashboard pages in order to modify restaurant data all within the frontend.
- A dynamic search system that allows the user to both sort through the restaurants & use our dynamic search bar.
- Reviews page to leave a review to share your opinions with others about Ames' restaurant.
- Plus more!

# Known Limitations
- We do have our database running on MongoDB Atlas, so while that does take off the difficulty of storing the data locally, the website may be slow at times
to load images, reviews, or restaurant data depending on how busy the MongoDB servers are.
